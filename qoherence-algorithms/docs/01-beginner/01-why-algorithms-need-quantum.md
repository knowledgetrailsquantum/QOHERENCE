# Why Some Algorithms Need a Quantum Computer (Beginner)

Not every problem benefits from quantum computing. Quantum algorithms only
help when a problem has special mathematical structure that superposition
and entanglement can exploit — like searching, factoring, or simulating
quantum systems themselves.

## The four algorithms here
- **Grover** — search faster.
- **Shor** — factor numbers faster (breaks RSA at large scale).
- **VQE** — find lowest-energy state of a molecule (chemistry).
- **QAOA** — approximately solve optimization problems.

If you're new, start by reading `qoherence-core`'s beginner docs first —
you need to understand qubits/gates/circuits before algorithms make sense.
